# 디자인 출시 전 체크리스트

## 위계·레이아웃
- [ ] 화면의 시선 출발점이 하나인가
- [ ] 강조색 CTA가 화면당 하나인가
- [ ] 그리드·정렬 기준선이 일관적인가
- [ ] 관련 요소 간격 < 구획 간격인가

## 타이포
- [ ] 스케일 외의 글자 크기가 없는가
- [ ] 본문 폭 ≤ 65ch, 행간 1.5~1.7
- [ ] 제목 줄바꿈이 어색하지 않은가(`text-wrap: balance`)
- [ ] 한글 단어 중간에서 끊기지 않는가(`word-break: keep-all`)

## 컬러
- [ ] 본문 4.5:1, 큰 글자/UI 3:1 이상 (계산으로 확인)
- [ ] 상태가 색 외 신호(아이콘·텍스트)로도 전달되는가
- [ ] 다크 모드 값이 별도로 검증되었는가

## 인터랙션·접근성
- [ ] 터치 영역 ≥ 44px
- [ ] 키보드로 모든 기능 접근, `:focus-visible` 표시
- [ ] hover / active / disabled / loading / error / empty 상태 정의
- [ ] 아이콘 버튼에 접근 가능한 이름(aria-label)
- [ ] `prefers-reduced-motion` 대응
- [ ] 폼 라벨·오류 메시지가 `label`/`aria-describedby`로 연결

## 반응형·성능
- [ ] 360 / 390 / 768 / 1280px에서 가로 넘침 없음
- [ ] 이미지에 크기·`alt`, 폰트 `font-display` 설정
- [ ] 불필요한 레이아웃 이동(CLS) 없음

## 검증 기록
스크린샷 경로와 확인한 뷰포트, 발견·수정한 문제를 보고에 포함한다.
